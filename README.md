# 손끝 트롬본 🎺

웹캠 앞에서 **손 높이로 음을 맞추고, 엄지+검지를 붙여 소리를 내는** 리듬게임이에요. 설치 없이 브라우저에서 바로 해요.

## 하는 법
1. **✋ 손을 위아래로** — 손이 높으면 높은 음, 낮으면 낮은 음
2. **🤏 엄지+검지 붙이기** — 붙이고 있는 동안 소리가 나요 (오래 불면 숨이 차요!)
3. **🎵 흘러오는 막대에 맞춰 불기** — 판정선에 닿을 때 막대 높이에 손을 맞춰요

카메라가 없으면 마우스(위아래 + 클릭/Space)로도 할 수 있어요.

## 어떻게 만들었나요
| 부분 | 도구 |
|---|---|
| 손 인식 | [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) (`@mediapipe/tasks-vision` 1.2.3 · `vendor/` 에 포함) |
| 소리 | Web Audio API — 악기·반주 모두 실시간 합성 (음원 파일 없음) |
| 화면 | Canvas 2D · 빌드 과정 없는 순수 HTML/CSS/JS |
| 배포 | GitHub Pages (https 라서 카메라 사용 가능) |

- 꼬집기 판단: 엄지 끝–검지 끝 거리 ÷ 손 크기(손목–중지 뿌리). 0.28 아래면 불기 시작, 0.45 위면 멈춤
- 채점: 음이 지나가는 동안 "불고 있고 + 음 높이가 ±1.1 반음 안"인 시간의 비율
- 곡: 작은 별 · 환희의 송가 · 징글벨 (모두 저작권이 끝난 멜로디)

## 개인정보
영상은 **내 브라우저 안에서만** 분석해요. 서버로 보내거나 저장하지 않고, 기록(최고 점수)은 내 브라우저에만 남아요.

